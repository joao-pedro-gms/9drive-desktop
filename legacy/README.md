# legacy/

The pre-desktop web app: Express + React + MySQL.

**Read-only reference. Not part of the new build.**

Nothing here is compiled, installed or deployed by the Tauri/Svelte application. The code
is kept only so the behaviour of the old app can be checked while the desktop rewrite is in
progress. Do not add features to it.

This directory is deleted at the F5 cutover.
